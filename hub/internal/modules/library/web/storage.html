从 Deck 向手机转移资源库（数据线 + ADB）

大量文件请用数据线，Wi-Fi 只有约 1MB/s。以下命令都在 Deck 的终端中、Z6xToolBox 目录下执行。

1. 连接
  • 数据线直接插 Deck 机身的 USB-C 口：经扩展坞时手机端 adb 每传几百 MB 就卡死一次。
  • 手机上打开「开发者选项 → USB 调试」（与无线调试是两个开关）。
  • 手机 USB 模式选仅充电：选「文件传输（MTP）」时，Deck 的桌面会自动打开手机、与 adb 抢占 USB，表现为插着线但 adb 找不到手机。同步脚本开始时会自动切换。
adb devices
2. 阻止手机相册扫描资源库（只需一次）
adb -d shell touch /storage/emulated/0/omni_library/.nomedia
3. 同步：只传缺少或大小不同的文件，可随时中断、重新运行即续传
./scripts/phone_push.sh ~/Games/omni_library/media_library/shortvideo/抖音 /storage/emulated/0/omni_library/media_library/shortvideo/抖音
./scripts/phone_push.sh ~/Games/omni_library/standalone_games/rpg_games /storage/emulated/0/omni_library/standalone_games/rpg_games
  • 手机上多出的文件不会被删除：SSD 与 SD 卡中同名但内容互补的文件夹可以先后同步到同一位置。
  • 断线时脚本自动重连；若提示「手机的 adb 卡住了」，拔下数据线再插上即可继续。
  • 软链接与只有大小写不同的同名文件会跳过并列出（手机存储不支持软链接、不区分大小写）。
  • 不要用 adb push --sync 续传：中断留下的半截文件修改时间较新，会被当作已传完。
4. 速度参考
  • 大视频约 30～40MB/s；大量小文件取决于文件数：每秒约 50 个，目录中文件上万时降到每秒几个（手机存储逐个建文件的开销，换传输方式也无法改善）。
  • 传完后 hub 最多 分钟内自动重新扫描；短视频封面由手机在后台补齐（Termux 中执行 thumbs status 查看进度）。

完整的说明、排查过程与原理见 Z6xToolBox 知识库「手机 → 向手机传输大量文件」。

其他转移方式

  • 投影仪：把 U 盘插到 Deck，在 omni-deck「存储与游戏库」中把它添加为资源库并移入内容；再插到投影仪，几秒内即出现在上方列表。
  • 少量：./hub/library-import.sh <文件夹> games.slg 经网络导入一个游戏（受 Wi-Fi 速度限制），存档随游戏目录一起转移。
  • 浏览器中可直接使用：网页游戏（RPG Maker、SLG）、CBZ 漫画、MP4 短视频；复古游戏与 Ren'Py 桌面版暂不支持。
