## 三个产物

| 产物 | 运行在哪里 | 用途 |
| --- | --- | --- |
| 桌面工具箱（Kotlin，Compose Multiplatform） | Linux / Steam Deck、Windows、macOS | 极米 Z6X Pro 与安卓手机的实践手册：每条命令标明执行位置与风险，输出来自真机实测；可连接设备读取信息、体检 |
| z6x-hub（Go） | 安卓设备（ADB 的 shell 身份，或 Termux） | 常驻服务：浏览器打开即为资源页（游戏、短视频、音声、漫画等），以及工具、设置 |
| z6x（Rust） | 安卓设备 | 命令集：系统指标、端口所属、按键注入、遥控器改键、查重、测速等 |

## 0.2.0 新增（z6x-hub）

- **资源首页**：标签分类、按需加载；游戏、短视频平台、工具在行末下拉菜单中选择。
- **短视频**：加权随机「推荐」、博主置顶（服务端保存）、全屏播放器、图集自动翻页；封面放在作品目录的 `.thumbs/`，由手机后台按温度调速生成。
- **音声**：专辑封面网格（读取 mp3 内嵌封面）。
- **设置页**：可调参数集中在 hub.yaml，网页上修改；管理可信 Wi-Fi；系统状态。
- **后台任务**：设备上的脚本（封面生成、遥控器改键）在网页上开关、设置开机自动启动。
- **AirPlay 音箱**：苹果设备可把音频推送到手机或投影仪。
- **Clash 白名单**（投影仪）：在原配置规则前加直连白名单，被拒绝的域名可一键加入。
- 登录密码（password）与本机地址 127.0.0.1 常开；监听被系统作废后自动恢复。

## 使用方式

**桌面工具箱**（自带 Java 运行时）
- Linux x86_64（含 Steam Deck）：`.deb`，或 `.tar.gz` 解压后运行 `Z6xToolBox/bin/Z6xToolBox`
- Windows：`.msi`（不需要管理员权限），或 `-portable.zip` 解压即用
- macOS（Apple Silicon）：`.dmg`。未经 Apple 公证，首次打开需在「系统设置 → 隐私与安全性」中允许

**安卓端程序** `z6x-android-<架构>-<版本>.tar.gz`（arm64 适用于大多数设备；arm 为只有 32 位用户空间的设备，此版本的 AirPlay 音箱不可用）
- 内含 z6x-hub、z6x、配置示例、开机与后台任务脚本，部署方法见包内 README.txt。

## 局限

- 桌面工具箱：下载的安装包可以完整阅读知识库；部署 hub、改键、连接设备等功能需要从源码运行（依赖仓库中的脚本与 Go 工具链）。
- z6x-hub 在 Termux 中（普通应用身份）读不到 CPU 使用率、网络流量，遥控、任务管理、通知不可用；这些需要以 ADB（shell 身份）运行。
- 手机息屏时 CPU 休眠：AirPlay 音箱在长时间息屏后可能搜不到，亮屏即恢复。AirPlay 只支持 AirPlay 1 音频，约 2 秒延迟。
- 短视频封面不在 hub 中生成：手机上由后台任务（Termux 的 python 与 ffmpeg）生成，大量作品需要数小时。
- 本项目针对极米 Z6X Pro 与 Redmi Note 12 Turbo（HyperOS）实测，其他设备上权限与路径可能不同。
